# 轻记 · 本地记账

[打开轻记](https://lee-0327.github.io/qingji-pocket/)

免费、免登录的静态网页工具。支持本机截图 OCR、一句话记账、分类习惯、微信/支付宝 CSV/XLSX 导入、流水统计、月预算、JSON 完整备份恢复。

账目使用浏览器本机 IndexedDB，不上传到本仓库或后台。默认本地识别；可选自备密钥的 AI 只在用户检查当次文字 / 裁剪图并确认后发送，服务商可能计费。密钥仅当前页内存，不写入账本、备份、存储或代码。首次加载页面和约 37MB 本地识别资料需要网络；“一句话”使用本地规则。网站能否在具体运营商网络打开，需要实际测试。

## 在 iPhone 桌面使用

1. 在 Safari 打开上面的链接。
2. 页面菜单 → 共享 → 添加到主屏幕。
3. 名称填“轻记”，开启“作为网页 App 打开”，点添加。
4. 从桌面图标打开，再到设置准备离线识别包，然后用少量旧截图试记。

Safari 和独立主屏网页 App 可能使用不同本地账本。若已在 Safari 记账，先导出 JSON 完整备份，再在主屏入口恢复，之后固定一个入口。换网址前也要备份；本工具没有跨设备自动同步。备份文件是明文，请妥善保管。

日常流程：截图 → 选图 → 核对金额、日期、分类 → 确认记下。系统截图自动触发是独立的实验入口，仍需 iPhone 实测；不可默认它与主屏 App 共享账本。

## 2026-10-28 截图识别修复

- 同一张图片在本机读取两次，兼顾中文详情和分散的大号金额，不增加网络接口。
- 兼容无标签店名、独立金额、同一行的多个字段及常见 OCR 空格。
- 不明确的金额保持待核对；核对页会指出缺失信息，支持临时查看、修正识别文字。
- 普通更新沿用同一地址；更新程序缓存不会清空本地账本。仍建议定期完整备份。

## 本地分类与简洁玻璃界面

- 商户、分类、用途分别显示；“巷口小面”可按“小面”线索建议餐饮。
- 餐饮支出有明确付款时间时，按时段建议早饭、午饭、晚饭或夜宵；咖啡、奶茶优先具体用途。只见手机时钟、缺日期或采集时间不会用来推断午饭。
- 分类建议展示依据，支持修改与记住商户分类；用途随 JSON 备份和 CSV 导入导出保留。
- 首页截图入口优先，浅色分组布局、系统字体与玻璃导航；这仍是网页工具，玻璃效果是网页近似实现。
- 分类与界面改版当时仍仅使用本机识别。后续版本新增了可选自备密钥 AI；默认不调用。普通更新保持相同地址和本地账本。

## 程序更新

2026.10.28.13：AI 记账新增“语音”按钮。首次先阅读说明并主动点“开始听写”，由浏览器 / 系统语音服务转成中文文字，最长 60 秒；停止后追加到现有输入，用户可修改，再明确点“发送给 AI”。不会自动发给 AI 或直接入账。取消、离开 AI 页、切后台或开始新对话会停止识别并忽略迟到结果。识别中断时保留已确认文字供用户主动填入；输入框已满时保留两份内容，不截断覆盖。

语音识别能力由浏览器、设备权限和系统设置决定，并非所有 Safari 主屏 App 或内置浏览器都能使用，且可能需要联网。轻记不保存录音、不把录音送到用户配置的 AI，也没有新增付费语音转写接口；浏览器或系统服务可能处理语音。不可用时显示键盘听写 / 打字入口。验收使用模拟语音事件和模拟 AI，无真实麦克风、语音服务或付费模型调用；实际 iPhone 权限与识别效果仍需实测。

2026.10.28.12（随 13 版发布）：底部新增“AI记账”。使用自己配置的接口，支持文字、键盘听写后的文字以及主动选取的图片；一句话可整理多笔，继续补充可更正未保存卡片。AI 只生成待确认卡片，用户点“记下”或补全核对后才写入本机账本；已保存卡片的修改复用原记录，重复提醒与撤销继续有效。

本次对话明确确认发送范围后，每次发送只请求一次。只发送当前输入、当前图片和未记下卡片的必要字段；不自动上传整本账。图片先在本机预览、可裁剪并移除元数据，文字模式禁止附图；没有自动重试或服务切换。密钥沿用当前页内存，对话和图片不进入账本备份，刷新后清空临时会话。正式保存沿用旧账兼容的记录格式，备注明确“AI 对话整理”。验收使用模拟接口，无真实密钥或付费调用。

2026.10.28.11：首页集中显示月度收支与按日流水；截图入口一键选图，一句话入口展开输入。分类统计可点入同月份、同类别的已确认支出与退款明细；可清除分类限定。核对页突出金额、商户、分类、用途，日期与备注等收进“更多信息”，风险与必填错误会展开。账单导入移到设置，AI 配置默认折叠。

本次新增一套原创淡彩猫咪贴纸：8个基础分类、咖啡/奶茶/买菜/书籍、收入/退款/截图/空态共16种。图片由内置 image_gen 新生成，用户参考图和竞品素材未放入程序。贴纸仅作装饰，本地显示并随页面缓存，分类仍以文字表达；没有新增账目字段或外部图片服务。

2026.10.28.10：商户识别存在差字或分店差异时，保留主要读法并列出候选供核对；修改候选仍参考本单商品信息，手动分类与用途优先。原始 OCR、商品线索和候选不会进入账目或备份。

新增可选自备密钥 AI，支持用户自填 Chat Completions 兼容 HTTPS 服务与模型。先本地预览、编辑文字，图片模式另预览可调整的裁剪图，再明确确认发送。每次只请求一次，不自动重试、切服务或保存建议；金额、日期和收支类型不由 AI 改写。其他使用者配置自己的接口，程序没有共享密钥或内置付费额度。

默认不调用 AI，本地功能继续免费。AI 密钥只在当前页面内存；地址和模型可选择保存在独立设置中，均不进入账本备份。选定服务会接收用于验证的密钥及该次预览，接口费用、数据政策和浏览器跨域访问由该服务决定。当前官方 DeepSeek 的无鉴权预检已允许本站来源；验收使用模拟接口，未用真实密钥进行付费调用，实际 iPhone 效果仍需核验。

首页右侧有固定“检查更新”，页底显示程序版本。没有新版时会明确显示已是最新；找到新版后保存或取消未完成的草稿，再更新。

旧页面没有入口时，在平时记账的同一浏览器打开[更新轻记](https://lee-0327.github.io/qingji-pocket/update.html)，点“更新轻记”，完成后回到同源账本。更新过程不清除账目、OCR资料或网站数据。
