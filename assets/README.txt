Original cat stickers for Qingji

qingji-cats-v2.png is an original illustration atlas made for this tool with
OpenAI's built-in image_gen. It uses newly generated cats and props. The user's
style reference and Shark bookkeeping screenshots are not included as pixels
or assets in this program.

4 columns by 4 rows, left to right:
meal, transport, shopping, home;
daily, health, fun, other;
coffee, tea, groceries, book;
income, refund, capture, empty.

The PNG has a genuine RGBA transparent background (1254 by 1254 pixels).
The app renders it locally with lib/stickers.js and ui-v2.css. Category labels,
amounts and action names remain accessible text; the artwork is decorative.
